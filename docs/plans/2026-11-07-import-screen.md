저장 형식: version:1, student:StudentInfo, records:CourseRecord[], standard:SchoolStandardOverride|null.
원본 파일/파일명/붙여넣기 원문은 저장하지 않는다. 편집 중에는 불변 행 ID와 수정 패치/삭제 표시를 유지한다.
다시 읽은 문서는 현재 문서의 파싱 결과를 교체한다. JSON/브라우저에서 복원한 과목은 새 문서에 없는 경우 보존한다.
저장 전 수정은 초안에서만 처리하며 명시적 저장으로 localStorage를 갱신한다. 실패/손상 저장소는 자동 덮어쓰기하지 않는다.
실제 포털 복사 텍스트의 탭/빈 칸 보존은 사용자 확인 항목이다.
