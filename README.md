# congraduate (중앙대 소프트웨어학부 졸업요건 시뮬레이터)

중앙대학교 소프트웨어학부 학생들을 위한 **졸업요건 판정 및 수강 계획 시뮬레이션 웹 서비스**입니다.

> 🔒 **개인정보 보호 원칙**: 서버와 데이터베이스가 없습니다. 성적 파일과 이수 내역은 **오직 사용자의 브라우저 메모리와 로컬 저장소(`localStorage`)에서만 처리**되며, 외부 서버로 절대 전송되지 않습니다.

---

## 🌟 주요 기능

1. **간편한 성적 이력 가져오기 (`/import`)**
   - 포털 문서 3종(공학교육인증 이수현황 PDF, 졸업관련성적내역 PDF, 졸업관련성적조회 xlsx) 브라우저 파싱
   - 포털 화면 복사/붙여넣기 및 과목 수동 추가/수정 지원
   - 카탈로그 검색 자동완성 및 중복 과목/재수강 자동 처리
   - 백업용 JSON 내보내기 및 불러오기

2. **졸업요건 종합 대시보드 (`/dashboard`)**
   - **공학인증(ABEEK) 기준**: 전문교양, BSM, 공학주제, 설계학점, 설계필수, 인증필수 판정
   - **학교 기준**: 전공필수, 전공선택, 교양필수, 핵심교양 영역별 최소 학점 및 이수 현황
   - 남은 필수 과목/영역 배지 목록 및 전문교양 미지정 경고 안내

3. **비학점 요건 체크리스트**
   - 자동 판정: 코딩부트캠프 Pass, 전공 영어강의 수 (원어구분 A/B 가중치 반영)
   - 직접 입력/체크: 공인영어(TOEIC 등), TOPCIT 점수 및 응시일 유효기간 판정, 지도교수 상담 횟수(학기당 1회 상한), 포트폴리오 7개 항목, SW중심대학 10개 트랙

4. **수강 계획 시뮬레이터 (`/plan`)**
   - 남은 정규 학기 및 계절학기 동적 생성
   - 2026 교과목 카탈로그 검색 및 학기별 장바구니 담기
   - 선수과목(AND/OR 조건) 및 설계 인정 학기 경고 안내
   - 수강 계획 반영 전후 비교 (졸업학점, 공학주제, 설계학점, 전공학점 변화 즉시 시뮬레이션)

## 🛠 기술 스택

- **프레임워크**: Next.js 16 (App Router, Static Export `output: 'export'`)
- **라이브러리**: React 19, TypeScript 5, Zod
- **문서 파서**: `pdfjs-dist` (CMap/Worker 자체 정적 호스팅), SheetJS (`xlsx`)
- **스타일**: Vanilla CSS (`globals.css`), 시맨틱 HTML 및 반응형 웹
- **테스트**: Vitest (단위·통합 테스트 277개 통과, 포털 공식 숫자 22개 일치 검증)

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속합니다.

### 3. 테스트 실행
```bash
npm test
```

### 4. 정적 빌드
```bash
npm run build
```
빌드 산출물은 `out/` 디렉터리에 생성됩니다.

## 📦 배포

GitHub Pages로 자동 배포되도록 GitHub Actions 워크플로우(`.github/workflows/deploy.yml`)가 설정되어 있습니다.  
`main` 브랜치에 코드를 푸시하면 자동으로 빌드 및 배포가 진행됩니다.
